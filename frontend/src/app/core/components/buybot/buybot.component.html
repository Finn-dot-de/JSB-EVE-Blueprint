TUTORIAL

So funktioniert Buybot 3000 in 5 Schritten:

  1. Asset-Liste kopieren. Markiere im EVE-Inventar, Hangar oder Vertragsfenster deine Items (Strg+A, Strg+C) und füge sie in das Textfeld oben ein.
  2. Abgabeort wählen. Im Dropdown den Ort auswählen, an dem du die Items abgeben möchtest. Das beeinflusst den Preis (Transport- und Sicherheitsaufschlag).
  3. Berechnen klicken. Buybot fragt live die aktuellen Jita-Marktpreise ab und erstellt eine Tabelle.
  4. Ergebnis prüfen. Lange Namen oder Status-Texte per Maus-Hover vollständig anzeigen lassen. Ein Hover auf den Preis einer Zeile zeigt den angewendeten Preis-Modifikator.
  5. Gesamtpreis kopieren. Mit dem Knopf neben der Endsumme wird der Gesamtpreis direkt in die Zwischenablage kopiert.

Status-Meldungen in der Ergebnistabelle: OK = wird angekauft, NICHT GELISTET = Kategorie/Item nicht freigegeben, GESPERRT = auf der Blacklist, NICHT GEFUNDEN = Item-Name konnte nicht erkannt werden.
